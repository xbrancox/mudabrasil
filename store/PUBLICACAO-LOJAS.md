# Publicacao nas lojas (PWA/TWA)

1. Gere os icones PNG (este reparo tenta automaticamente via Edge/Chrome headless).
2. Confira store/twa-config.json.
3. Use PWABuilder ou Bubblewrap para gerar o pacote Android.
4. No Play Console, use a politica de privacidade ja publicada.
5. Comece pelo track interno antes da producao.
